# 数据驱动恢复：布局、关系与证据

用于固定/低信息输出、来源不明的数据表、代码与数据关系不清，或准备尝试离线变换的场景。目的是恢复校验输入、文本、配置或载荷；不能因此授权在线口令尝试或扩大目标范围。

## 先区分待回答的问题

| 已有证据 | 可考虑的方法 | 仍须保留的不确定性 |
|---|---|---|
| `F(input) == stored` | 可逆则求逆；有路径约束可建模求原像 | 多对一函数可能多解，哈希/MAC 不能套直接求逆 |
| `F(stored) == input` | 提取并正向应用已确认变换 | 还需确认输出是哪个判定阶段的输入 |
| blob 与判定关系未知 | 提取数据、寻找消费点；有线索再约束搜索 | 只能称恢复假设，不能预写成“密文里就是答案” |
| 可达路径会生成目标数据 | 在允许的后端观察相关中间态 | 摘要校验、输入派生密钥或外部状态可能从不生成明文 |

固定输出、规整表长和未找到解码器不构成“二中三”判型。记录实际输入与路径；未知正例时不要声称正确输入也输出固定内容。无 xref 可能来自计算指针、重定位、初始化、间接跳转或分析缺口；零引用扫描只列候选。多个比较也可能是分段验证，不预设最后一个才有效。

## 取出可解释的数据

使用现有 read_views / const_scan / unreferenced_data 等工具时，记录样本哈希、文件偏移或虚拟地址、长度、元素宽度、端序与切片依据；命令参数以实际 --help 为准。保留邻接对象和边界，避免把 padding、另一张表或字符串终止字节拼入密文。

文件字节、加载后的映像与初始化/解码后的内存是不同版本。bss 可能没有对应文件内容；重定位、自修改、构造函数和运行时改表需分别记录。若数据以 stack/tight/decoded strings 形式生成，可考虑已有运行时观察或 FLOSS 等工具的适用路径；FLOSS 不保证恢复没有解码逻辑的未知密文。

长度与周期约束都带来源：

- `strlen` 约束相应路径上的输入字节，可能受 NUL、换行、编码和 padding 影响，不自动等于明文长度。
- 固定输出 N 次可提出长度候选；没有依赖证据时也可能只是计数器或进度。
- `i & 3` / `%4` 要核对操作数、索引和元素宽度，可能是四个 u32 元素或环形槽位，而不是四字节密钥。
- 短表可作密钥、S 盒、alphabet 或普通常量。高熵和 16/32/64 字节对齐不单独确定角色。

布局不明时考虑端序、UTF-16、交织、分块或压缩等有线索的解释；不是默认尝试所有格式。

## 选择恢复方法

已有可信变换链时直接重放、提取或逐段求逆，不为“完整流程”再扫一遍。输入/输出关系有约束时可用已有 SMT、局部反推或已知明文约束；前缀也是假设，需留出格式未知或非文本结果。

没有解码链但有有限参数候选时，读 [复合变换与搜索](transform-pipelines.md)。未知密钥空间很大或疑似强加密时，寻找密钥来源、算法/模式、运行时状态通常比加深字节变换搜索更有信息。搜索无命中不证明程序不可解。

现有 xor_scan.py 只做窄范围单字节搜索和逐位置分组的周期密钥频率猜测。猜出一把周期密钥不等于覆盖全部该周期密钥。binary/短文本可能不符合频率模型。

## 验证与交接

搜索器固定测试向量通过，只支持工具基本实现；编码/解码往返可能共享错误。可按需要比较独立实现、实际中间态、完整结构或未修改目标上的判定，不能仅验前两字节。

模型与运行冲突时，先检查读数、ABI、初始状态、位宽和环境，再选断点、trace、局部仿真或静态证明；见 re-dynamic 的 function-oracle.md 与 coverage-review.md。没有可靠 oracle 时保持候选状态，不凭“可打印”“有括号”或打补丁后的通过宣布接受。

复用现有 experiment/claim/source：记录输入数据版本、变换与参数来源、搜索实际覆盖、候选产物哈希、验证层次和未排除范围。秘密内容留在受保护产物中，用引用交接；不灌入普通共享记忆。不要因尝试次数多或 worker 多而重复同一搜索空间。
