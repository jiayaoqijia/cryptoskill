# Security

Use the latest reviewed release or a commit you have inspected. The package
contains research instructions and local development utilities; it does not
request trading credentials or execute trades.

For a security issue, use **Security → Report a vulnerability** on GitHub when
private reporting is available. If it is unavailable, open an issue requesting a
private reporting channel without including exploit details or sensitive data.
Never post API keys, account information, or private research inputs.

Report factual errors, missing sources, and ordinary prompt-quality issues through
the normal issue tracker, with the relevant request and public evidence.
