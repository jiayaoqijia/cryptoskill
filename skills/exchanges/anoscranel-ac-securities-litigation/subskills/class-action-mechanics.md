# Class action mechanics

## Standard

A securities class action begins with a complaint filed on behalf of a putative class, and it becomes a class action only when a court certifies it. Between those points there is a lead-plaintiff process, in which the court appoints the investor with the largest financial interest to direct the litigation, a motion to dismiss, and discovery. Most cases that survive the motion to dismiss settle rather than proceed to trial.

The class definition sets the boundaries. It names the security, the period, and often the market in which the shares traded, and an investor outside those boundaries has no claim even if the loss is real. Reading the definition before assuming entitlement is the first step, and the class period is usually the second thing to check against the holding dates.

Primary sources: <https://www.sec.gov/investor> and <https://www.cfainstitute.org/>.

## Decision rules

- Record the filing date, the court, and the alleged misstatement period.
- Record the class definition: security, period, and market.
- Record whether the class has been certified and on what date.
- Record the lead plaintiff and any competing applications.
- Record the procedural stage: motion to dismiss, discovery, mediation, settlement.
- Record the deadlines that bind a class member, distinct from those binding the lead plaintiff.

## Procedure

1. Record the case identifiers and the alleged period.
2. Read the class definition and test the holding against it.
3. Record the certification status.
4. Record the lead Plaintiff and the stage reached.
5. Record the deadlines applicable to absent class members.
6. Write the case summary with the stage.

## Anti-patterns

- Assuming participation without checking the class definition.
- Confusing the lead-plaintiff deadline with the claim deadline.
- Treating a filing as a case that will proceed.
- Ignoring the market qualifier in the class definition.
- Assuming a settlement ends the matter for all holdings.

## Done checklist

- [ ] Case identifiers and period recorded.
- [ ] Class definition tested against the holding.
- [ ] Certification status recorded.
- [ ] Lead plaintiff recorded.
- [ ] Stage recorded.
- [ ] Deadlines recorded.

The stage also determines what a holder can do: before certification there is nothing to join, after certification there are absent-class-member rights, and after settlement there is only a claim deadline. Reading which stage applies prevents the common error of treating a filing notice as a settlement notice and either doing nothing or acting too early.
