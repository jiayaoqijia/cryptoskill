# Quality record

## Standard

The quality record states each question, the filing and line that raises it, and what evidence would answer it. Framing the output as questions with references keeps the analysis honest: it distinguishes an observation about the accounts from an allegation about the management, and it gives a later reader the ability to check whether the answer arrived.

The record also carries the pattern across periods, because single-period observations are weak. A receivables build in one quarter is a fact; the same build in five consecutive quarters with revenue decelerating is a finding, and only the series makes the difference visible. The record is therefore indexed by question and accumulated across periods rather than rewritten each time.

Primary sources: <https://www.sec.gov/edgar/search/> and <https://osf.io/prereg/>.

## Decision rules

- Each entry states one question, in a single sentence.
- Each entry cites the filing, the statement, and the line or note.
- Each entry records the period and the size of the item in currency and as a ratio.
- Each entry states what would answer the question, and whether it has been answered.
- Entries accumulate across periods; answered questions are marked rather than deleted.
- The record distinguishes an accounting observation from an inference about intent.

## Procedure

1. Write the question and its size.
2. Cite the filing and the specific line.
3. Record the period and the comparison basis.
4. State the answering evidence.
5. Track the answer across subsequent filings.
6. Review the accumulated entries at each reporting period.

## Anti-patterns

- Writing a conclusion where a question belongs.
- Citing a filing without the line or note.
- Deleting a question once it is answered instead of marking it.
- Presenting an inference about intent as an observation about the accounts.
- Reviewing one period without the series.

## Done checklist

- [ ] Question stated in one sentence.
- [ ] Filing and line cited.
- [ ] Size and period recorded.
- [ ] Answering evidence stated.
- [ ] Answer tracked across filings.
- [ ] Observation separated from inference.

The record's greatest value appears when the same question is asked in a later period and the answer has changed: an accrual gap that closed, a receivable build that reversed, or an adjustment that stopped recurring are all evidence that the earlier concern was either transient or addressed, and only a maintained record can show which.
