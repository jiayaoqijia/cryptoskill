## Purpose

Draft low-fidelity landing page wireframe structure, section logic, and content placeholders.

## Use when

- You need structural page layout and section hierarchy before visual design execution.
- There is no existing page to audit, so this is a build draft rather than CRO review.

## Required inputs

- Offer goals, audience intent, and CTA priorities [client-provided].
- Context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Any mandatory content, legal notes, and conversion constraints.

## Safety/authority

- No fabricated proof points, testimonials, or metrics in placeholders.
- Wireframe draft only; no production publishing or coding actions.
- Mark missing evidence blocks as [client-provided].

## Workflow

1. Define page objective and primary conversion action.
2. Sequence sections using problem → value → proof → CTA logic.
3. Specify placeholder copy intent per section.
4. List validation tests and unresolved dependencies.

## Output format
```

- Wireframe narrative
- Section blueprint (section | purpose | key elements)
- Placeholder copy guidance
- Validation checklist and unknowns
```

## Quality checks

- Section flow aligns with stated audience journey and CTA.
- All proof-related placeholders avoid invented claims.
