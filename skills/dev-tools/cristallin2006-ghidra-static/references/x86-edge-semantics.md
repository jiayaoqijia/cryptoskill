# x86 边缘语义与位域/编码结构识别

CTF rev 的「校验函数」经常不是考算法，而是考**机器语义的边缘情况**——
反编译器会忠实翻译指令却抹掉语义陷阱。本表是识别清单：看到指令/模式 →
想起语义 → 知道约束该怎么建。

## 一、flags 是关键材料，不只是分支条件

程序用 `pushfq; pop reg; and reg, MASK` 把 CPU flags **序列化为校验材料**
（和输入一起进 hash/key 派生）时：解题不仅要给出正确的值，还要给出
**产生正确 flags 的值**。约束系统里必须有 flags 变量，不能只有数据变量。

| 指令序列 | 语义陷阱 | 建模要点 |
|---|---|---|
| `ucomisd x, 0.0` 遇 NaN | unordered：ZF=PF=CF=**1** | NaN 比较不是「不等」，是「无序」 |
| `cvttsd2si` 转换溢出/NaN | 无效转换被 MXCSR mask 时 EAX=`0x80000000`(integer indefinite)，**且不动已有 flags** | 前一条指令的 flags 会穿透下来 |
| `cmpxchg [m], r` | 相等：ZF=1 且写回；不等：ZF=0 且 **RAX←[m]** 不写 | 「让校验通过」可能要求比较**失败** |
| `pabsd` | `abs(INT_MIN)=INT_MIN`（符号位不清） | 唯一特例值，常是题眼 |
| `movmskps` | 每 lane 取符号位组成掩码 | mask 约束 → 各 lane 符号位约束 |
| `rol/ror r, cl` | 计数取模：32 位 `&31`,64 位 `&63` | cl 的高位被丢弃 |
| **64 位 `rol rax,3` 后只用 EAX** | 低 32 位 = `c << 3`(**不是** rol32!) | 位宽混淆是反编译器高发误诊区 |
| `rep movsb` | 计数由 RCX 定，与缓冲区声明长度无关 | count 可溢出相邻栈字段（off-by-one 覆盖紧邻的指针/变量） |
| `bt/bts/btr` | 位串操作，进位 CF=被测位 | 位图结构信号 |

**反编译器不显示 flags 来源时（伪码里 flags 凭空出现）→ 一律看汇编**，
找 `pushfq/lahf/setcc` 的捕获点。

## 二、位域/编码结构识别

看到位运算约束系统，先问：**能不能按位域拆成独立小子问题**？
能拆 → 逐段枚举/模逆/查表（秒级）;**拆都不拆直接 SMT 是烧时间**
（gate_smt 管流程，本表管知识——先识别结构再决定工具）。

| 结构 | 指纹 | 拆法 |
|---|---|---|
| IEEE-754 double | 64 位常量比较 + `movq xmm` + 浮点比较 | sign(1)/exp(11)/mantissa(52) 三段；quiet NaN = exp 全 1 + quiet bit + payload≠0；约束常落在 payload 子域 |
| 位域打包整数 | 一串 `shr/and/shl/or` | 画出每段的 [hi:lo] 区间，段间无进位运算 → 独立求解 |
| 旋转+异或链 | `rol/ror` + `xor` 交替 | ARX 结构，逐轮可逆——手写逆，不要 SMT |
| 模乘 | 乘大奇数常量 | 奇数在 mod 2^n 下必有逆元（`pow(a,-1,1<<n)`)，乘法是双射 |
| SIMD 分 lane | `pabsd/paddd/pshufb` 等 | 每 lane 独立 32/16/8 位问题 |
| 查表置换 | 常量表 + 索引运算 | S-box/置换表： dump 表 → 逆查表 |

通用动作：**拆出来的每个子问题都先用小规模枚举/封闭形式试**（16 路枚举 ×
模逆之类），全部失败才上 SMT；SMT 前必须过剥离闸（peel_inverse.py →
cone_invert.py,gate_smt 机械拦）。

## 三、序列化/转录（transcript）模式

多段校验题常见架构：每阶段的「输入 + 机器观测（寄存器/flags/掩码）」被
序列化后进 hash，作为下一阶段 key 材料。识别信号：domain 分隔的 hash
常量串、manifest/表驱动的分段、每阶段末尾有一次 hash 调用。

- 序列化是**原始字节**，不是 hex 文本——重建时字节序/位宽错一个，key 全错
- 观测字段必须**忠实重建机器值**（含 flags 全位、掩码、状态字），不是「能过比较的值」
- 认证（AEAD tag / hash 比对）天然是**候选过滤器**:SMT/枚举出多个候选时，
  用下一层解密认证当 oracle 筛——「算术满足 ≠ key 正确」
