# Plain Language

## Overview

Three leaves cover plainness as a governed craft. plain-language.md applies the ISO 24495-1 principles: relevant, findable, understandable, usable. readability-measures.md scores the result and organises testing with readers. inclusive-accessible.md keeps the text bias-free and accessible, alt text and Easy Read included.

## When to use

- Rewriting a public document so its intended readers can find, understand and use it.
- Scoring readability and designing a before/after reader test.
- An inclusive-language pass: bias-free humans language, disability wording, alt text, Easy Read.

## When not to use

- A one-off "make this clearer" pass on a reply or a single sentence — outside this skill.
- Picking a base style guide or building the project style sheet — outside this skill.
- A full structural revision — outside this skill.
