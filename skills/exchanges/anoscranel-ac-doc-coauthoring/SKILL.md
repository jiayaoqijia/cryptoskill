# Document Co-Authoring

## Overview

Structured documents fail when authored in a single monolithic pass without upfront alignment or iterative testing. This skill governs the interactive co-authoring loop between an author and an agent across three formal stages: context gathering, section planning and iterative building, followed by reader testing and decision recording. It focuses entirely on managing the collaborative process and pacing, leaving specific domain conventions and line-level editing to dedicated sibling skills.

## When to use

Use this skill when collaborating on substantial multi-section documents requiring careful alignment, such as formal proposals, technical specifications, product requirement documents, design documents, architecture records, and Request for Comments. It ensures shared intent is established before writing begins and maintains rigorous quality gates through iterative section locks.

## When NOT to use

Do not use this skill for quick, single-paragraph memos or scratchpad notes where process overhead exceeds value. It is not for producing a standalone first draft without interaction (use ac-drafting), line-editing an existing completed draft (use ac-editing), or establishing domain-specific document conventions (use ac-spec-writing).

## Status and honest limits

Status is seedling. This skill governs the interactive collaboration loop and structural progression of document authoring. It does not automate domain research, perform deep fact-checking of external claims, or replace the author's substantive judgment on strategic business decisions.
