## Decision rules

Pick the row by the guide named or the task's genre. Cite the edition the table carries — never one it cannot back. If the row is ⚠️-flagged, say the flag.

## Procedure

1. Match the question to a row. 2. Read back name, edition, date, scope, any ⚠️ flag. 3. Stop — genre how-tos live in the craft skills.

## Anti-patterns

- Stating an edition or date not in the table.
- Adding genre procedures or checklists here.

## Done checklist

- [ ] Answer carries name + edition + date + flag exactly as the row states them.
