# 静态分析：证据与输入约定

用于本技能的语义建模和交接；它是核对依据，不是每题全量扫描清单。

## 明确正在解释哪个对象

样本哈希、函数/地址、分析选项和人工类型修正限定结论。文件偏移、虚拟地址、加载映像、初始化后内存不是同一份数据；重定位、自修改、bss 和运行时改表可能使它们不同。反汇编、建函数和类型修正可改变保存的分析状态；比较前后行为时说明干预，不把修复后的视图冒充原始基线。

常量和输入注明长度、元素宽度、端序、切片依据、NUL/换行及编码处理。`i & 3` 可能索引四个字而非四个字节；相邻对象、终止符和 padding 不自动属于同一密文。需要核对时提取相关原始字节，不为单点问题默认导出整个程序。

## 证据支持什么

伪码可支持局部解释和导航，也可能受类型、控制流或渲染错误影响。结论依赖有疑点的区域时，选择指令、P-code、原始字节或运行行为交叉核对。低层视图本身也依赖处理器模式、地址和分析状态；不要把某一层当成永远正确。

跳转表告警不直接证明缺陷，尾调用可能触发类似警告。无 xref 不等于无消费者；异常、信号和间接跳转可能补全不可见路径。注释、变量名和工具诊断是线索，不替代实际数据流。

## 候选与验证

先分清 `F(input)==stored`、`F(stored)==input` 和关系未知，不能默认都是求逆。独立实现或已知向量能检查模型局部语义；同源往返可能共享错误。完整字节、结构及未修改目标的相关判定比可打印率或短前缀更有证明力。缺运行后端时允许交付有范围的静态结论。

交接保留关键地址/来源、模型适用范围、候选产物与未确定条件。对拍不一致时可检查 ABI、位宽、初始状态和搬运链，也保留算法模型有错的可能。
