# Coding findings

## Standard

Coding takes the findings of each primary study — the authors' own results, not the reviewers' summaries of them — and assigns meaningful labels to every segment. The unit is the finding as the original author stated it. Each code carries the study's context along with it: setting, participants, and the author's interpretation travel with the coded text, because the same words in two different participant groups mean different things. Findings that contradict each other are coded as they stand rather than reconciled during coding.

Coding discipline is what makes the synthesis auditable: every code should be traceable to the exact text it was assigned to. A code exists because a specific passage supports it; a theme that later can no longer point to its coded passages is a conclusion, not a synthesis. This traceability is what distinguishes thematic synthesis from thematic essay-writing.

Primary sources: <https://bmcmedresmethodol.biomedcentral.com/articles/10.1186/1471-2288-8-45> and <https://www.biomedcentral.com/methods>.

## Decision rules

- Extract the original authors' findings verbatim or with explicit paraphrase markers.
- Attach context metadata — participants, setting, and study identity — to every finding.
- Code every finding in the set; do not skip findings that fail to fit.
- Contradictions are coded faithfully, not resolved by preference.
- Record each code's location so that any theme can be traced back to its passages.
- An abridged audit confirms that a sample of codes can be traced to their exact source texts.

## Procedure

1. Extract the findings of each primary study with their context metadata into a common format.
2. Read the first study's findings and assign codes staying close to the original language.
3. Apply the second study, adding codes only where existing ones fail to fit.
4. Continue iteratively, recording new codes and the study that prompted each.
5. Maintain an audit table mapping every coded passage to study, page, and exact text.
6. Check the audit table against the themes when the themes are built.

## Anti-patterns

- Coding the reviewers' summaries rather than the original findings.
- Coding only findings that resonate; leaving unhelpful studies coded.
- Resolving contradictions during coding rather than recording them.
- Dropping short or dull findings.
- Building themes first, then assigning codes that match.

## Done checklist

- [ ] Findings verbatim or marked as paraphrase.
- [ ] Context attached to every passage.
- [ ] Every finding coded, contradictory or not.
- [ ] New codes recorded with the study that prompted them.
- [ ] Audit table matches codes to exact source text.
- [ ] Traceability from theme to coded passage verified.
