# Academic Writing

## Overview

Two leaves cover scholarly documents. academic-papers.md structures original reporting: IMRaD, reporting guidelines by study type, submission and reviewer response. literature-review.md structures synthesis: narrative and systematic reviews, search reporting, screening and PRISMA conduct.

## When to use

- Structuring a paper, reporting by guideline, drafting the response letter to reviewers.
- Writing a narrative or systematic review: protocol, screening flow, synthesis.

## When not to use

- Executing the database search and set assembly itself — outside this skill.
- Binding claims to checkable sources in a reference list — outside this skill.
