# Ideation

## Overview

Two different jobs hide under "brainstorming": generating many options, and cutting them down to a few worth testing. They must not share a meeting, because judgment kills generation. This skill runs both as separate passes: frame the question, diverge, converge, capture, and leave a written record so the session survives its own author.

## When to use

- Someone asks for options: "brainstorm this", "generate options", "we need ideas", "how might we".
- A team or a solo operator is stuck and needs a wider set of alternatives before choosing.
- A long list of ideas needs to be shortlisted honestly, with scores and a next test.

## When NOT to use

Attacking an existing plan is outside; ac-interrogation covers that. Writing requirements is outside; ac-spec-writing covers that. Deciding alone is outside: this skill produces options and a shortlist, never the decision. A routine single-answer question needs one idea, not a session.

## Status and honest limits

- Seedling: built from the public canon cited in each leaf; the full pass order has not been stress-tested across many live sessions.
- The skill raises the quantity and quality of options and makes the shortlist defensible. It does not make the choice, and it cannot guarantee a good idea exists in the space searched.
- The quantity rules rest partly on lab studies of face-to-face groups (⚠️, divergence-rules); treat those as directional, not law.
