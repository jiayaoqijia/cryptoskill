## Purpose
Build professional services qualification, objection-handling, and close workflows aligned to pipeline and calendar operations.

## Use when
- You are operating inside `SalesPortl-Professional-Services-Skills-Suite`.
- You need professional services execution quality for consultancies, law/accounting firms, and advisory practices.
- You want repeatable, improving workflows that learn from each run via context + memory updates.

## Industry fit: micro-niche variants
- advisory retainers
- project-based consulting
- specialized legal/accounting engagements

## Standard operating patterns (SOP)
- discovery and scope alignment
- compliance-aware messaging review
- engagement onboarding and review cadence

## SalesPortl platform tooling focus (if available in workspace)
- campaign setup for expertise-led demand gen
- workflow nodes for intake→proposal→onboarding
- pipeline stages for opportunity→engagement

## Required inputs
- Business objective and requested deliverable
- Current context quality (none/partial/verified)
- Business model, offer mix, and target customer profile
- Authority boundary for external actions (draft-only unless approved)
- Available SalesPortl platform features in this workspace

## Workflow
1. Define qualification gates and disqualification criteria.
2. Build stage-by-stage messaging for discovery, objection handling, and close.
3. Translate playbook to CRM pipeline stages, SLA timers, and follow-up calendar tasks.
4. Add review loop for conversion leakage with corrective actions by stage.

- Workflow/automation nodes
- Custom agent launch and role-specialized sub-agents
- CRM pipeline and lead stage automation
- Calendar, booking, and follow-up automations
- Website/page/app builder flows (where available)
