## Purpose

Build scene-by-scene storyboard drafts for video narratives, transitions, and production alignment.

## Use when

- Video concepts need visual sequencing before production or editing starts.
- You need scene planning rather than final script polish or edit technicals alone.

## Required inputs

- Story objective and key message [client-provided].
- Brand/client context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Known assets, location limits, and production constraints.

## Safety/authority

- No invented footage, talent availability, or rights assumptions.
- Storyboard is planning draft only; no production approvals implied.
- Explicitly label unknown scene assets as [client-provided].

## Workflow

1. Define beginning/middle/end narrative arc and scene goals.
2. Draft per-scene visual intent, dialogue/voiceover, and transition logic.
3. Identify required assets, props, and dependencies per scene.
4. Add review checkpoints for narrative clarity and feasibility.

## Output format
```

- Storyboard overview
- Scene table (scene | visual intent | audio/dialogue | transition | dependencies)
- Production risk notes
- Review checklist
```

## Quality checks

- Scene sequence supports narrative objective and CTA clarity.
- Dependencies and feasibility constraints are captured without assumptions.
