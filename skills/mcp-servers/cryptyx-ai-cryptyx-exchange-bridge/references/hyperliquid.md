# Hyperliquid

Hyperliquid has no single official MCP server. Several community servers exist. Use the one the user has connected and follow its documentation.

- **Read positions:** use the connection's read-only account or position tool. Perpetual positions are listed per coin (e.g. `ETH`). Send only the coin symbols to CRYPTYX, not position size, side or leverage.
- **Spot vs perps:** spot balances and perp positions may come from different calls. Include the coins from whichever the user asked about.
- **Orders:** place, change or cancel only through the connection's own tools, with the user's explicit approval.

Use the tool names the connection actually exposes. Do not guess them.
