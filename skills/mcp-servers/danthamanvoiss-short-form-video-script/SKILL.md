## Purpose

Draft short-form video scripts with hook, narrative beats, CTA, and platform-fit pacing.

## Use when

- You need spoken/on-screen script language for short-form social video content.
- The task is scriptwriting, not detailed edit timeline planning.

## Required inputs

- Objective, audience, and desired CTA [client-provided].
- Brand context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Platform, duration target, and prohibited claims.

## Safety/authority

- No fabricated testimonials, metrics, or compliance-sensitive claims.
- Mark unverified proof statements as [client-provided].
- Output script drafts only; no automated publish steps.

## Workflow

1. Define core message and audience tension to resolve.
2. Draft hook, body beats, and close CTA aligned to duration target.
3. Provide alternative tonal variants if requested.
4. Add validation questions for factual/compliance review.

## Output format
```

- Primary script draft
- Optional variant scripts
- Shot/onscreen cue notes
- Fact-check and compliance prompts
```

## Quality checks

- Script pacing matches platform/duration constraints.
- All claims are verified or explicitly marked for confirmation.
