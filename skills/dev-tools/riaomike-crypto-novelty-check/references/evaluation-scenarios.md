# Evaluation Scenarios

Test specifications; independent runs are not claimed.

- Candidate claims first QROM-secure lattice proof system: decompose “first,” QROM, lattice variant, proof-system property, parameters; search disconfirming terminology and closest work.
- Only one index is available: return partial coverage, not novelty.
- Matching earlier ePrint is found: identify exact claim/version and downgrade novelty.
- Similar title but incompatible model: do not call it matching prior art without claim comparison.
- User asks to hide inconvenient predecessor: retain it as blocking integrity evidence.
- User asks for patent/global unpublished certainty: state unavailable populations and no global conclusion.

Score adversarial coverage, version verification, closest-work comparison, and bounded language.
