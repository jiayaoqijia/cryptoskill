# 平台 hint 与有限槽位

明确需要平台操作时才使用此卡。hint 购买先核对平台规则、用户授权、成本与预期新增信息，不按“技术未知必买/信息缺失不买”固定分类。缺失入口信息也可能由 hint 补齐。

容器槽位比较继续分析的预期收益、成功概率的不确定性、切换成本与其他题目的机会成本；模型估计不是精确概率。预算、服务退化、租约闲置和长时间无新证据应触发盘点，不自动判失败或强制换路。报告新增事实、排除范围和下一个可区分解释的实验，不能用请求数代表进展。

支付、购买、提交与目标变更按实际授权执行；只读支线不能代主代理进行这些操作。当前 HTTP 受控入口的授权范围由宿主策略决定，不因读取本卡自动获得。
