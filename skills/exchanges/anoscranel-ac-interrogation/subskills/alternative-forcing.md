# Alternative Forcing

## Standard

- **Bezos, Amazon shareholder letter (2015)**: distinguish one-way doors — irreversible, decide slowly — from two-way doors — reversible, decide quickly and correct course. ⚠️ cited without URL.
- **Duke, _Quit_ (2022)**: every choice buys one option with all the others; opportunity cost is the unselected list. ⚠️ cited without URL.
- **Socratic method** (Stanford Encyclopedia of Philosophy, "Socrates"): examine the preferred claim by testing what it excludes; the case is understood through the alternatives it rules out. <https://plato.stanford.edu/entries/socrates/>
- ⚠️ Practitioner convention: do-nothing is always an alternative; when the status quo is missing from the option set, the comparison is rigged.

## Decision rules

1. If fewer than three alternatives exist, keep generating; two options make a referendum, not a choice.
2. If do-nothing is missing, add it and cost it like the others; keeping the current state is a decision.
3. If the door is two-way, pick the cheapest candidate and learn from doing; long analysis of a reversible choice wastes the reversibility.
4. If the door is one-way, spend the analysis time; the cost of being wrong is the price of the session.
5. If alternatives differ only in name, they are fake; change at least one structural premise — scope, means, or timing.
6. If an option's cost is stated without what it displaces, add the opportunity cost: what else the budget and attention would buy.
7. If the plan survives only because of money already spent, name the sunk cost and re-decide as if starting fresh today.

## Procedure

1. Restate the preferred option as one candidate among many, not the default.
2. Generate at least three alternatives: a scaled-down version, a different means to the same goal, and do-nothing. Add a wildcard when the stakes are high.
3. For each option, write three lines: cost, reversibility, and what it displaces.
4. Classify the decision: one-way (irreversible or expensive to undo) or two-way (reversible).
5. Fix the comparison criteria before scoring, then apply the same criteria to every option.
6. Ask the swap question: "if option B were the proposal, would anyone propose option A?" If nobody would, A is over-favoured.
7. Choose — or run two cheap options in parallel when the door is two-way.

## Anti-patterns

- **The false choice.** "Do this or fail" hides the real option set. Fix: force the third option into view.
- **Do-nothing as cowardice.** Dismissed without a cost line. Fix: price it like any option.
- **Cosmetic variants.** Three wrappers around one plan. Fix: vary scope, means, or timing.
- **Sunk-cost lock-in.** "We have come too far to stop." Fix: re-decide as if starting fresh.
- **Reversibility ignored.** Deep analysis of a two-way door, or a snap call on a one-way one. Fix: classify the door first.
- **Opportunity cost unstated.** The displaced option never appears. Fix: name what the same time and money would otherwise buy.

## Done checklist

- [ ] At least three alternatives generated, do-nothing among them.
- [ ] Every option carries cost, reversibility, and displaced value.
- [ ] Door type named for this decision.
- [ ] Identical criteria applied to all options.
- [ ] Swap question asked and answered.
