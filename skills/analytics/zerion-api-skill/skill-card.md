## Description: <br>
Query real-time crypto wallet portfolios, transactions, DeFi positions, NFTs, token prices, and gas fees across EVM chains and Solana using Zerion's API. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers, analysts, and product teams use this skill to ask an agent for wallet portfolios, transaction histories, DeFi positions, NFTs, token prices, gas prices, and related crypto market context through Zerion's remote MCP server. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Wallet addresses, portfolio lookups, transaction-history requests, and related analysis intent are sent to Zerion's remote MCP service. <br>
Mitigation: Use a dedicated Zerion API key, submit only authorized wallet research, and avoid confidential customer lists, non-consensual targets, or sensitive internal investigation notes. <br>
