## Purpose

Draft post-meeting recap, commitments, and next-step follow-up messages with explicit unknowns.

## Use when

- A sales or strategy meeting has completed and stakeholders need a clean recap.
- You need send-ready drafts that separate confirmed decisions from pending items.

## Required inputs

- Meeting notes/transcript highlights [client-provided].
- Participant roles and expected next actions.
- Brand/client context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.

## Safety/authority

- No invented agreements, approvals, dates, or performance claims.
- Mark tentative items as [pending confirmation].
- Draft-only output; no automatic send actions.

## Workflow

1. Extract decisions, commitments, risks, and unresolved questions.
2. Draft audience-specific follow-up version(s) as needed.
3. Create action table with owner/date placeholders.
4. Add confirmation prompts for any ambiguous notes.

## Output format
```

- Meeting recap summary
- Action tracker (owner | action | due date | status)
- Follow-up draft message(s)
- Open questions / confirmation requests
```

## Quality checks

- Every commitment has a source note or is flagged pending confirmation.
- Tone, terminology, and scope align with provided context templates.
