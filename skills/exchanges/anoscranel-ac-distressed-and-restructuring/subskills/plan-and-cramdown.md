# Plan and cramdown

## Standard

A plan of reorganisation allocates the reorganized company's value among the claims, and confirmation requires each impaired class to accept it by the statutory majorities. Acceptance is counted by class, not by holder: a class accepts when a majority in number and two-thirds in amount vote in favour, which is why control of a class's composition is worth more than control of a single large position.

Cramdown is the mechanism for confirming a plan when a class does not accept. It permits confirmation over a dissenting class provided the plan is fair and equitable and does not discriminate unfairly, which in practice means the class must receive at least what it would in liquidation and the priority order must hold. The protection is real but narrow: a junior class cannot receive value while a senior class is impaired, and the "fair and equitable" test is where most cramdown litigation lives.

Primary sources: <https://www.uscourts.gov/> and <https://www.law.cornell.edu/>.

## Decision rules

- Record the plan's classes and which are impaired.
- Record the treatment of each class: cash, new debt, equity, or reinstatement.
- Record the votes by class in both number and amount.
- Record which classes accept and which are crammed down.
- Record the liquidation analysis that supports the fairness test.
- Record the effective date conditions, which determine when the new instruments exist.

## Procedure

1. Read the plan and the disclosure statement.
2. Record classes, impairment, and treatment.
3. Record the voting results by class.
4. Identify the crammed classes and the fairness arguments.
5. Record the liquidation analysis and its assumptions.
6. Write the summary with the effective date conditions.

## Anti-patterns

- Counting votes by amount and ignoring the number requirement.
- Treating a plan as certain before the effective date conditions are met.
- Assuming cramdown overrides absolute priority.
- Ignoring that a class can be impaired but accept.
- Overlooking the liquidation analysis, which anchors the fairness test.

## Done checklist

- [ ] Classes and impairment recorded.
- [ ] Treatment per class recorded.
- [ ] Votes recorded by number and amount.
- [ ] Crammed classes identified.
- [ ] Liquidation analysis recorded.
- [ ] Effective date conditions recorded.

The voting mechanics also reward early positioning: a claim acquired before the record date carries a vote, while one acquired after it does not, so the same economic exposure can have very different influence depending on when it was assembled. That distinction between economic interest and voting power is a recurring feature of the process and belongs in the analysis rather than in a footnote.
