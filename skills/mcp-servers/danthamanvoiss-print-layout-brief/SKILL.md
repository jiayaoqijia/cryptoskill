## Purpose

Draft print layout requirements for brochures, flyers, one-pagers, and similar collateral.

## Use when

- A physical print piece requires structured layout requirements before design execution.
- The task is print collateral layout definition, not packaging design.

## Required inputs

- Collateral objective, format size, and audience [client-provided].
- Brand/client context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Printer constraints, finishing options, and legal copy requirements.

## Safety/authority

- No invented print specs, legal claims, or printer approvals.
- No final print production actions; brief-only output.
- Use placeholders for unknown technical specs ([client-provided]).

## Workflow

1. Define communication hierarchy and required content blocks.
2. Map layout zones, reading flow, and CTA placement.
3. Capture technical constraints (size, bleed, safe area, folds, finishing).
4. List prepress dependencies and approval checks.

## Output format
```

- Print layout brief summary
- Layout structure map
- Technical specification checklist
- Approval/dependency list
```

## Quality checks

- Brief includes all required prepress constraints without guessing.
- Use-when boundary remains distinct from packaging design briefs.
