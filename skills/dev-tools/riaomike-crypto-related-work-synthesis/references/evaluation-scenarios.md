# Evaluation Scenarios

Test specifications; independent runs are not claimed.

- Synthesize verified papers on folding schemes by model, assumptions, extraction, recursion cost, and limitations: build evidence-linked taxonomy and comparisons.
- Corpus contains only titles/abstracts: mark full-text claim synthesis unavailable.
- Same work has ePrint and conference versions: preserve material version differences.
- User asks “prove our method is first”: route to novelty audit; do not turn synthesis into proof of novelty.
- Costs use incompatible hardware/parameters: qualify or refuse ranking.
- Request is one-paper summary: route to paper reader.

Score citation support, comparison compatibility, gap calibration, and output shape.
