## Purpose

Draft social graphic concept packages with message hierarchy, layout intent, and asset requirements.

## Use when

- A campaign needs static social visual concepts before production.
- You need concept direction for social graphics, not full content calendar operations.

## Required inputs

- Campaign objective, channel specs, and message priorities [client-provided].
- Brand/client context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Available assets and format constraints.

## Safety/authority

- No fabricated brand assets, model rights, or performance claims in mock concepts.
- Concept drafts only; no final design export/publishing actions.
- Use placeholders for missing assets ([client-provided]).

## Workflow

1. Define visual hierarchy and CTA emphasis per format.
2. Draft concept variants by tone/style direction.
3. List required assets and copy dependencies.
4. Add review criteria and adaptation notes by channel.

## Output format
```

- Concept summary
- Variant table (concept | intent | layout notes | required assets)
- Channel adaptation notes
- Review checklist
```

## Quality checks

- Concepts remain aligned with approved brand constraints and campaign objective.
- Asset dependencies are explicit and non-fabricated.
