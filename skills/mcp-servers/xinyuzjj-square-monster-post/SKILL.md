# Square Monster Post（妖币广场发文 · 剧本三轴）

## ⚠️ 先分流：这是两套分析技巧，不是同一个工具的两种参数

| | **代币** → `square-rich-post` | **妖币** → 本技能 |
|---|---|---|
| 看什么 | **市场结构** —— 价格由众多参与者共同堆出来 | **控盘意图** —— 价格由庄家按剧本演出来 |
| 关键概念 | 结构 HH/HL、BOS・CHoCH、扫流动性、OTE 0.618-0.705、OB、FVG | **位阶**（演到第几格）、**控盘度**（盘在谁手里）、**燃料**（油从哪来） |
| 主周期 | 4h | 15m/1h 触发 + 日线位阶 |
| 止损 | SMC 结构失效位 | **固定 10%**（妖币的结构位不可信，挂结构止损等于把止损位送给庄家） |
| 方向 | 结构定多空 | **只做多，绝不做空** |
| 出场 | 结构破位 | **剧本切换**（进派发即离场）+ 自极值回撤 12% 移动止盈 |

**判断走哪条**：这只币在「行情 → 妖币雷达」里出现过 → 用本技能；否则用 rich。
拿不准就直接跑本技能 —— 它不在雷达视野内会**明确报错并提示改用 rich**，不会硬编一篇。

> 为什么不能共用：妖币的每一次「回踩支撑」都可能是画给你看的诱多，每一次「扫流动性」
> 就是专门去点你的止损。SMC 的前提（结构位背后真的有人挂单）在控盘盘上不成立。

## 命令

| 命令 | 说明 |
|---|---|
| `node cli.mjs <SYMBOL> [market=futures]` | 只合成不出：出封面图 + 竖版剧本卡 + 稿子，打印位阶/控盘/燃料/合议结论 |
| `node cli.mjs <SYMBOL> [market] --publish` | 合成后发布 **短贴多图**（封面 + 竖版剧本卡显示在正文里，默认形态） |
| `node cli.mjs <SYMBOL> [market] --publish --article` | 长文+封面（contentType=2；OpenAPI 限制：正文无法插图） |
| `node cli.mjs <SYMBOL> --publish --reuse <目录>` | 复用已合成目录（改稿后重发） |

示例：`run_skill square-monster-post "RAVEUSDT --publish"` / `run_skill square-monster-post "VTHOUSDT"`（纯预览）

## 产物（workspace/square_monster/<SYM>_<ts>/）

- `cover.png` — 1280×720 封面：90 日走势（面积填充）+ **剧本进度带**（七格，当前格高亮+指针）+ 三轴卡 + 底部读数条（位阶/控盘/燃料/费率/OI）
- `chart_playbook.png` — 1080×1080 **竖版剧本卡**（手机可读）：合议结论 + 剧本进度带 + 这一格/下一格 + 控盘与燃料 + **出场四段**
- `title.txt` / `article.txt` — 组稿（正文含 `$BASE` cashtag 与 `#话题` 标签）
- `meta.json` — 统计 + 三轴读数 + `plan` + `exit_segments` + `missing`（数据缺失清单）

## 稿件结构（剧本引擎）

1. 开头：现价 / 24h / 30d，然后说明**为什么不聊指标**
2. 三轴拆解：
   - **① 位阶**：主剧本七格里的第几格 + 这一格在演什么 + 下一格是什么
   - **② 控盘度**：命中的控盘指纹（无现货 / 合约独大 / 换手畸高 / 空头付钱 / 拉升无爆仓）
   - **③ 燃料**：费率 / OI 蓄力 / OI 脉冲 / 大户拥挤 / 买盘主导 / 爆仓结构，逐条给读数
3. **合议结论**：可埋伏 / 窗口已过 / 持仓者减 / 离场不接 / 不参与 / 只观察
4. 操作计划：**只在「可埋伏」时给点位**（入场=现价不追高、止损固定 −10%、达标减半、其余交给回撤 12% 移动止盈）
5. 出场四条线：认输线 / 达标线 / 移动止盈 / 提前落袋
6. 文末固定：风险提示 + 开源链接 github.com/xinyuzjj/bazz.agent

## 四套妖币专属风格（`--style` 可指定，默认随机）

| 风格 | 语气 |
|---|---|
| `playbook` 剧本拆解体 | 像拆一集剧，讲清庄家在干什么 |
| `hunt` 埋伏笔记体 | 第一人称，猎人记等待日志 |
| `warn` 别接盘体 | 站在「你可能正要去追」的位置上劝 |
| `plain` 说人话体 | 极简，只给结论 |

> 与代币引擎的 `review/diary/qa/blunt` 刻意不重名 —— 名字不同是为了让 agent 不能顺手互换。

## 铁律

1. **只做多，绝不做空。** 安装版真实战绩：3 笔做空全部被轧空击穿 10% 强平线，最大有利仅 0.0% / 0.0% / 1.4%。妖币的顶常是二次拉升前的换手。
2. **止损固定 10%，不要改成结构位。** 控盘盘的结构位是画出来的。
3. **不给点位也是结论。** 位阶不在允许窗口时，稿子必须明说「本次不给点位」，绝不硬造方向。
4. **数据缺失要如实标注**（`missing` 字段），缺 OI 就说「位阶的晚不晚只按价格判」。
5. **出场四段与 `radar_tracker` 同口径**（10% / 25% / 12% / 反转因子），不许在稿子里写别的数。
6. 每日 100 帖上限（square-post 官方配额）。

## Agent 约定

1. `--publish` 前无需再确认密钥（square-post 自动读取）。
2. 想改稿：改完用 `--reuse <目录>` 重发，或直接走 `square-post text --text-file <改稿> --title <标题>`。
3. 判断失误（把普通代币丢进本技能）会拿到明确报错 + 改用建议 —— **不要因此改用 rich 硬发一篇妖币文**。
4. 稿子里的三轴读数全部来自 Monster Radar 同源数据，agent 不要自行替换成别的指标。
