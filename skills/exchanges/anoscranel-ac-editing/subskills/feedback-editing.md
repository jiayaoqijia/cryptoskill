# Feedback & editing

## Standard

- **A critique is a face-threatening act, so it is redressed.** Criticism of another's work threatens the writer's positive face — the self-image they claim. Weightiness Wx = social distance + the writer's power over you + the imposition's rank (<https://www.historicalpoliteness.net/bibliography/>). A higher sum buys more deference in the note.
- **The query apparatus is codified.** CMOS 18e §2.75 is titled "Writing Author Comments and Queries"; the prefix "**AU:**" makes queries greppable so none goes unanswered. "Stet" cancels a proposed change (<https://www.chicagomanualofstyle.org/qanda/data/faq/topics/Abbreviations.html>).
- **Three response types:** mark errors per the agreed sheet; query for the author to stet or change; flag for awareness only.
- **Delivery in 2026:** Word Track Changes with in-line comments, author resolving accept/reject. A style sheet and cover letter ship with the file — the sheet is a deliverable.
- **Workplace comments:** situation, behaviour, impact, plus a next step. Patterns over incidents ("missed timelines on 3 of 5 projects", not "missed the Q3 deadline") (<https://clawhub.ai/1kalin/afrexai-performance-review>).

## Decision rules

1. Fix mechanical errors silently against the agreed sheet. Query every judgment call.
2. Ask or suggest; do not instruct — asking "gives the author control over how they respond" (⚠️ practitioner rung).
3. One issue per query, one clear sentence.
4. Frame notes reader-side: "readers may find this contradictory", not "this is confusing".
5. State the action — "please add the source here". Open questions invite the answer "yes".
6. Never ask the author to verify all facts; query a fact only with the reason it seems off.
7. Prioritise: blocking, substantive, line, nits. Order the notes the same way.
8. Late-stage notes respect production: a major change at final proof has knock-on effects.

## Procedure

1. Read the draft once without marking. Name the pass — structural, stylistic, copyedit, proofread — in the letter.
2. Agree the basis first: guide, house sheet, brief. No sheet, no consistency notes.
3. Edit in Track Changes. Mechanical fixes against the sheet; meaning changes are queried, not silently rewritten.
4. Write each query on its own line starting "AU:". One issue, one sentence, one action. Use initials ("Safety:") when several reviewers comment.
5. Write the letter: what the draft is, the one thing to fix first, the ordered notes, what you did not change and why, how to find the queries.
6. Read the notes aloud. Anything that reads as a verdict on the writer gets rewritten.
7. Transmit marked file, style sheet and letter together.

## Anti-patterns

- Rewriting another's draft silently and presenting it as corrected.
- Queries that instruct rather than ask.
- Twenty undifferentiated comments with no priority.
- Asking the author to verify every fact.
- Personality labels ("lazy writing") where behaviour and impact belong.

## Done checklist

- [ ] Pass named and scope agreed before marking.
- [ ] Mechanical fixes applied; judgment calls queried only.
- [ ] Every query starts "AU:", carries one issue and one action.
- [ ] Letter carries priorities and the unchanged-and-why list.
- [ ] Notes read aloud; none reads as a verdict on the writer.
- [ ] File, sheet and letter delivered together.
