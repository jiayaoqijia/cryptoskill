# VM 语义、状态版本与条件化求逆

取指/分发器、固定指令记录、嵌入式程序或原地多轮变换影响当前结论时按需读。不要求完整模拟所有 handler，不把 opcode 名称、容器魔数或自带 --disasm 的输出自动当真值。

## 从消费路径恢复语义

核对取指宽度/端序、指令边界、寄存器/内存位宽、标志更新、PC 单位与更新时点、异常与步数预算。低字节 rotate 可能保留高位，而某个 STAGE/审计名字的操作也可能改值并清高位。名称不决定副作用；SIMD 初始化看实际写入范围及相关读写，不把所有 auVar 表达式建成算法，也不将向量代码一概视为 memset。

分别记录 opcode 已观测/已实现/未覆盖；未知指令、截断、无效 PC 和预算耗尽不静默当 NOP 或 FAIL。actual_halt_opcode 未观测时保持 missing；从 status 推出的 halt 标为 derived，不当第二条独立证据。分支的真实谓词比 JNZ/JZ 的昵称可靠。

容器候选按结构长度、解码、checksum、语义 magic、loader 实际选择分别判断。魔数字符串可能只是说明；checksum 通过但 magic 拒绝不等于所有校验失败。loader 未选段先称 rejected/unselected，不能凭名称/大小/当前输入无影响就断言全局诱饵。

## 就地更新与可逆条件

对每步覆盖的分量，区分读取旧值/本轮新值、别名与先前覆盖。逆序执行各步能复原读取版本，但每一步仍须对被覆盖分量可逆，且其他需要的数据还在。自引用 `x=(x+x) mod 256` 把 0 和 128 都映为 0，倒序也救不回信息。偶数乘数、截断、重复覆盖、非单射表或分支相关信息需另判。

小域查表可检查覆盖/唯一性，碰撞和缺项不能用 inverse[out]=in 静默盖掉。双向往返只验证所测模型/样本，可能共享错误；小域穷举、结构证明、独立输入与实际目标观察有不同支持范围。已有可信局部语义可直接求逆再重放，不强制先建完整解释器或先跑随机样本。

参数提取带地址、样本/程序版本、字段位宽和覆盖范围；不把每个 STM 块强行当完整一轮，前导/尾部/异常分支单独识别。操作计数是结构线索，不是普遍的长度或轮数证明。

## 验证的层次

模型往返、选定状态摘要一致、未改样本在某个后端接受、补丁后输出是不同结论。有限字段未覆盖的寄存器高位/内存/分支仍未知；32 位摘要不能唯一标识较长输入，来自同一程序的多项检查可能共享常量/逻辑。唯一解需要完整输入域、接受路径、约束和双射依据，不能从可打印/弱 hash/少量随机测试推定。

自带结构化报告适合做局部对照，先说明原始字段和派生字段、PC 单位、计数时点、初态及输入递交方式。见 re-dynamic/references/state-fingerprint-oracle.md。Wine、原生和仿真各自限定环境；原文件未改不消除后端差异。

无直接调用方只表示当前分析没直接边，回调/异常/导出/间接调用都可能存在。相关时用现有 unreferenced_funcs 定位候选；不全题必扫、不自动调用或 patch。实验副本的结果不证明原始可达性或 BOF 利用成功。
