# Grey literature and registers

## Standard

The bibliographic databases index what journals publish, and what they miss is not random: unpublished trials, reports that live on agency websites, theses, preprints, and conference abstracts that never became papers. Since publication itself is biased toward favorable findings, a search confined to the indexed literature samples the biased subset — which is the argument for searching grey sources at all.

Registers are the structured half of that effort. A trial registered before recruitment began carries the outcome the investigators planned, so it disciplines both publication bias and outcome-switching regardless of whether the trial ever reached print. Searching registers finds the studies that exist but did not publish, and comparing register entries to published reports finds the outcomes that quietly disappeared.

Primary sources: <https://register.clinicaltrials.gov> and <https://training.cochrane.org/handbook>.

## Decision rules

- Search at least one trial register with the review's terms, and record the search like any database.
- State which grey sources were searched: agency reports, theses, preprints, and conference archives as applicable.
- For each register hit, record status: completed, published, terminated, or unknown.
- Compare registered outcomes with published reports for included studies.
- Record the date of register searching; registers grow and change.
- Treat grey sources with the same eligibility criteria as journal-published studies.

## Procedure

1. Choose the register and grey sources appropriate to the question's domain.
2. Run the search and log terms, date, and yield as for any database.
3. Screen register results against the same eligibility criteria.
4. Match register entries to publications for all included studies.
5. Record status and registered outcomes for each match.
6. Note in the conduct record what the registers revealed that the databases did not.

## Anti-patterns

- Database-only searching justified by the inconvenience of grey sources.
- Register results excluded without applying the stated criteria.
- Published outcomes taken at face value without checking the registration.
- Grey sources searched but not logged, so the effort is unverifiable.
- Register matches ignored when the trial was terminated.

## Done checklist

- [ ] At least one register searched and logged.
- [ ] Grey sources named and searched.
- [ ] Register statuses recorded.
- [ ] Registered outcomes compared to publications.
- [ ] Register search dated.
- [ ] Eligibility applied equally to grey results.

The register comparison also disciplines the review's own scope: a registered trial that meets the eligibility criteria but was never published must appear in the flow record as identified and excluded only for a reason the criteria actually name. Silent omission of an eligible unpublished trial is publication bias operating inside the review itself, and the register search is the only instrument that can catch it.
