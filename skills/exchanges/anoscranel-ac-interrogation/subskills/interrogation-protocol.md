# Interrogation Protocol

## Standard

- **Socratic method** (Stanford Encyclopedia of Philosophy, "Socrates"): the elenchus exposes inconsistency through questions; the questioner asks and the claim-holder examines. The interrogator does not deliver the verdict. <https://plato.stanford.edu/entries/socrates/>
- **Klein, "Performing a Project Premortem"** (HBR, 2007): the failure exercise runs before commitment, while the plan can still change. <https://hbr.org/2007/09/performing-a-project-premortem> ⚠️ paywalled.
- **Brooks & John, "The Surprising Power of Questions"** (HBR, 2018): questions open information that assertions close; follow-ups carry the diagnostic work. <https://hbr.org/2018/05/the-surprising-power-of-questions> ⚠️ paywalled.
- ⚠️ House convention: six stages in a fixed order — purpose and stakes, assumptions, evidence, failure modes, alternatives, commitment.

## Decision rules

1. If the decision, its stakes, and its owner are not stated, do not start; ask first.
2. If the plan has not been read cold first, read it before asking anything.
3. If the door is two-way and stakes are small, batch the questions and keep the session under 20 minutes.
4. If the door is one-way, question serially: one question at a time, each answer shaping the next.
5. If the time-box expires, stop where you are and report what remains unresolved.
6. If an answer opens a larger question, follow it; the stage order serves truth, not tidiness.
7. If the session covers the same ground twice, move to close.

## Procedure

1. **Cold read.** Read the full plan once before any question. No notes, no interruptions. Write the decision it encodes in one sentence.
2. **Frame.** State purpose and stakes: what gets committed, when, at what cost. Name the door type: one-way or two-way.
3. **Contract.** Say the harness line: "I ask, you answer; you decide." Set a time-box, 30-45 minutes by default.
4. **Assumptions.** Inventory what the plan takes for granted; separate load-bearing from incidental.
5. **Evidence.** Ask what evidence exists, how strong it is, and what would change the author's mind.
6. **Failure modes.** Run the pre-mortem and inversion; name the failure that actually ends the plan.
7. **Alternatives.** Generate at least three options plus do-nothing; check reversibility and opportunity cost.
8. **Commitment.** Restate the revised plan in the author's words, list unresolved items, set kill criteria, and confirm that the owner decides.

## Anti-patterns

- **Failure modes first.** Leading with "what could go wrong" makes the author defensive before the plan has been understood. Fix: cold read, then assumptions.
- **Cross-examination.** Rapid serial questions meant to corner, not clarify. Fix: one question, wait, follow the answer.
- **No time-box.** The session drifts into a second meeting nobody planned. Fix: set the clock at the frame, stop at expiry.
- **Skipping the cold read.** Questions reveal you did not read past page one. Fix: read everything first, silently.
- **Deciding for the owner.** The questioner announces a verdict the author must adopt. Fix: restate options; the owner commits.

## Done checklist

- [ ] Decision and stakes stated in one line each.
- [ ] Plan read cold before the first question.
- [ ] Six stages run in order, or skips recorded with reasons.
- [ ] Time-box set and respected.
- [ ] Revised plan and unresolved items written down.
