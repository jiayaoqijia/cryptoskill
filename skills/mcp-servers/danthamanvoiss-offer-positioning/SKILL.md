## Purpose
Produce claim-safe positioning for agency offers using approved context only.

## Use when
- Launching or revising service offers.
- Aligning messaging across sales and marketing.

## Required inputs
- Approved brand/offer context.
- Target segments and common pains.
- Available proof assets or proof gaps.

## Safety/authority
- Use only approved brand claims; do not invent outcomes.
- Insert proof-required flags wherever claims need evidence.
- No legal/financial advice or guarantees.

## Workflow
1. Define ICP and exclusion profile.
2. Map pain -> outcome -> differentiator chain.
3. Draft messaging pillars and proof requirements.
4. Generate claims approval checklist.

## Output format
```
- ICP summary
- Pain/outcome map
- Differentiators
- Messaging pillars
- Claims gate checklist
```

## Quality checks
- Each value claim has proof status.
- Pillars align with approved context.
