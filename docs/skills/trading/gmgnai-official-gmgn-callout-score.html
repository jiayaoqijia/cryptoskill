Gmgnai Official Gmgn Callout Score

Trading by @gmgnai v1.0.0 B PASS 5 flags

Decide whether to act on a caller's (喊单人) calls. Scores one call-out wallet on two axes — SELECTION (do the coins he calls actually run) and POST-CALL CONDUCT (does he sell into the attention his own call created) — then returns a follow / don't-follow verdict. The conduct axis is proved from the caller's own per-trade ledger, not from any self-reported field: for each sampled coin it compares the first buy, the call timestamp, and every sell after it, so "he dumped on his followers" is a measured sequence rather than an inference. USE THIS SKILL WHEN the user asks whether a caller is worth following: 这个喊单的能不能跟, 这个喊单号靠不靠谱, 喊单信誉分, 喊单评分, 他喊完会不会砸盘, 他是不是喊完就卖, 跟他的单能不能吃到, caller 评分, is this caller trustworthy, can I follow this caller's calls, does he dump after calling, call-out credibility score, score this caller. Accepts either a GMGN profile handle (twitter_username, e.g. the last path segment of a gmgn.ai/profile/<handle> link) or a wallet address; a handle is resolved to one (chain, wallet) pair in Step 0 and the resolution is always echoed. The same questions in any other language route here — match on meaning, not wording. DO NOT USE THIS SKILL for raw call-out data — "这个钱包 喊过什么单", "最新喊单", "谁在喊这个币", "KOL 在喊什么", the feed, the field dump, the 30d summary card — that is gmgn-callout, which owns every read of the callout endpoints and returns them untouched; this skill calls it and adds a verdict. Nor for a caller judged as a trader rather than as a caller ("这个钱包能不能跟单", "跟单评分", copy-trade backtest) — that is gmgn-wallet-analysis / gmgn-wallet-score, which read his trades and know nothing about his calls. Nor for a token the caller mentioned ("他喊的那个币安全吗", 尽调, rug check) — that is gmgn-contract-dd. Nor for a token creator's next launch ("这个 dev 的新盘能不能买") — that is gmgn-dev-score. A bare wallet address with no call-out intent stays with gmgn-wallet-analysis; a bare token address stays with gmgn-contract-dd. This skill needs the word 喊单 / caller / call-out in the ask to own it. TIE-BREAKS, because three words are shared with neighbouring skills: 喊单 paired with 能不能跟 / 信誉 / 砸盘 / 评分 routes HERE, while 喊单 paired with 喊过什么 / 最新 / 谁在喊 / 列表 routes to gmgn-callout — the first group asks for a judgement, the second for rows. 能不能跟 without 喊单 is about a wallet as a trader and stays with gmgn-wallet-analysis / gmgn-wallet-review. 信誉 without 喊单 is a launcher question and stays with gmgn-dev-score. PRESET PHRASES this skill is written to answer, each carrying the call-out intent word: 「帮我看看 [喊单人ID或地址] 这个喊单的能 不能跟」「[喊单人ID] 喊的币能跟吗」「查一下 [钱包地址] 的喊单信誉」「这个喊单号喊完会不会 砸盘:[地址]」. WHAT IT CANNOT ANSWER, so the ask goes elsewhere: whether any one called coin is safe to buy (gmgn-contract-dd); what he is calling right now (gmgn-callout global); whether he is a good trader to copy (gmgn-wallet-score); who else called the same coin or whether he called it first (no per-token caller list exists in the CLI, so it is not computable at all); how much he staked on a call (readable only in the unfilterable global feed); anything older than 30 days (callout record covers 30d only).
