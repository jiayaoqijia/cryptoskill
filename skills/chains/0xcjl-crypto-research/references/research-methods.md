# 分类研究方法

## 共同底稿

确认官网/文档/社交账号与链上资产身份。官方合约或原生资产由原始文档和链浏览器交叉核对，DEX 名称和最高市值候选不是身份认证。搜索可返回多个候选；模型决定哪个与用户意图一致，无法消歧则询问。

用当前产品、实际使用与近期变化回答“是什么、处于什么阶段、为什么值得继续看”。关键事实打开原文；合作双方、用户或独立资料检验单方宣传。团队履历、融资金额、注册主体、项目品牌不混为一谈。只记录公开人物职业相关信息，不搜集不必要个人信息。

标准研究覆盖以下适用项，按问题分配篇幅；quick 保留身份、业务/机制、近期发展、核心风险与缺口；deep 追查矛盾、反证、同行及关键链上行为。

## 无币产品/服务

- 解决的问题、目标用户、产品是否可用、核心功能、价格与交付方式。
- 客户/使用案例及其可验证性；用户、付费客户、合作方分开。
- 商业模式、融资、团队及持续经营能力；无披露就写未知。
- 直接竞品、替代方案、差异化，以及最近30/90天有证据的进展。
- 集成依赖、托管/权限、数据/安全及业务风险。不开交易模板；不把积分/测试网活动自动当作空投。

## 发币前项目

在项目底稿上增加：测试网/主网、可验证用户和非刷量使用、交付与路线图、融资参与者激励、公开代币分配及TGE状态。比较获取关注或参与活动的时间、资金、权限和机会成本。任何空投资格/发币日期/分配只引用官方已公布内容；传闻单列且不得据此承诺收益。

## 有产品/协议的已发币项目

分开评估产品采用与代币持有者受益。费用、协议收入、持币者收入、回购和销毁按实际规则及治理状态核查，未执行提案不当作既成事实。

| 类型 | 优先指标与风险 |
|---|---|
| L1/原生资产 | 实际经济活动、费用/发行/销毁、验证者与质押、生态资金和开发交付；剔除机器人投票等口径差异 |
| L2 | 桥及稳定币变化、使用、排序器经济、结算成本、升级/退出与治理风险；不能把链流量直接归于治理币 |
| DeFi | TVL与真实资金流、费用/收入/持币者分配、借款/利用率或交易量、激励成本、清算/坏账/合约与预言机依赖 |
| AI/DePIN/基础设施 | 可验证付费需求、服务消耗、供给/补贴、代币需求与排放；节点数和故事不等于收入 |
| RWA/稳定币 | 储备、发行/赎回、权利主体、审计/鉴证范围、抵押及脱锚、托管/监管依赖；稳定币不套普通上涨目标 |
| 包装/质押凭证 | 底层资产、兑换率/赎回队列、桥或托管、双重计算与脱锚 |

代币部分读 opportunities.md，研究分配/流通/成本/解锁/做市、链上变化及市场结构。先选可比项目与指标再比较，不能仅凭FDV差额给目标价。

## 注意力驱动项目/代币：先排雷

优先顺序：身份 → 合约与控制 → 可买卖/池子 → 关联筹码 → 叙事与传播。检查铸币/冻结/转账收费/黑名单/升级权限、部署者及LP控制、早期买家和关联资金、异常成交、官方被冒用/接管等。

通过浏览器/模拟/已知工具做只读检查，不实际下单验证卖出。交易模拟未做就写未验证；无权限不是无风险，放弃mint权限也不证明安全。Solana 分别检查传统Token和Token-2022扩展，不能把标准发行平台视为免检查。

排雷分为“已证实重大风险、存在待核实风险、未发现重大问题但覆盖有限”。这是模型基于证据的判断；不输出“绝对安全”。证实关键风险或身份不明时先报告，不继续编造买入机会。

通过后深挖：创始人/开发者可验证履历和历史、产品是否真实（纯meme无产品不机械扣分）、文化/叙事起源、社交扩散与筹码/流动性。匿名、长龄账号、知名关注者都不能单独证明信誉。
