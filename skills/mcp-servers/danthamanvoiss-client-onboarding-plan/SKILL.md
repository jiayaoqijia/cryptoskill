## Purpose
Create an implementation-ready onboarding plan from confirmed deal context.

## Use when
- Starting a new client engagement.
- Aligning scope, access, and responsibilities.

## Required inputs
- Approved scope and timeline.
- Stakeholders and communication preferences.
- Access requirements for relevant platforms.

## Safety/authority
- Draft-only planning output; no account/system changes.
- No promises beyond approved scope.
- Include escalation path for blockers and compliance concerns.

## Workflow
1. Confirm scope and kickoff objective.
2. Build access/dependency checklist.
3. Define first 30/60/90-day timeline.
4. Set communication cadence and success measures.

## Output format
```
- Kickoff agenda
- Access checklist
- Timeline
- Communication plan
- Success measures
```

## Quality checks
- Plan aligns to scope and constraints.
- Dependencies and owners are explicit.
