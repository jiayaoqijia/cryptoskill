# Evaluation Scenarios

Test specifications; independent runs are not claimed.

- Draft a CRYPTO-style paper from a verified construction with measured benchmarks: produce the four-part abstract under the word cap, contributions bullets, comparison table, technical overview, and venue structure.
- Compress an existing AI-flavored draft for a named venue: report the de-AI grep hits, rewrite each category (vocabulary/structure/content), and show before/after for the abstract and one body section without changing claims or numbers.
- User gives a draft but no target venue: return structure-neutral guidance and ask for the venue before any format claim.
- Page limit or template may have changed since training: verify the venue's official site and record a dated policy snapshot instead of asserting remembered rules.
- De-identification gap (author names or identifying repository links present): fix before format checks and report the edits.
- Claim without a body address (number in the abstract missing from the evaluation section): expose it and do not smooth it over.

Score abstract discipline, de-AI completeness, claim-to-body addressability, double-blind compliance, and absence of fabricated content.
