# 图表风格规范（日报）

## 目标

- 保持专业、简洁、可读，不做“图形炫技”。
- 避免审美疲劳：不使用“全柱状图”。
- 每张图只回答一个问题，图型与问题强绑定。

## 视觉统一

- 统一主题色：蓝系为主，正负变化使用绿/红，BTC 用橙色。
- 统一网格与字体：弱网格、清晰数字、留白充足。
- 统一标注：关键值直接标在图上，避免读者二次换算。

## 图型映射（默认）

1. `chart_market_snapshot_levels`
- 图型：KPI 卡片（总市值 / 24h 成交 / BTC.D）
- 原因：该图是“水平快照”，读数优先，不需要趋势轴。

2. `chart_market_daily_change`
- 图型：极简棒棒糖（相对前日变化）
- 原因：强调方向与幅度，减少柱体视觉噪声。

3. `chart_market_breadth_snapshot`
- 图型：100% 堆叠条（BTC / Top2-10 / Top10外）
- 原因：这是结构占比问题，100% 组合最直接。

4. `chart_exchange_24h_change`
- 图型：横向棒棒糖排名
- 原因：便于比较交易所强弱和分化。

5. `chart_top10_assets_24h`
- 图型：单行热力格（Top10 24h 涨跌）
- 原因：快速看全体方向和分化程度。

6. `chart_exchange_spot_deriv_structure`
- 图型：按交易所 100% 堆叠条（Spot vs Derivatives）
- 原因：核心是“结构占比”，不是总量竞赛。
- 备注：右侧可附总成交额标签（B USD）补足规模信息。

7. `chart_derivatives_snapshot`
- 图型：雷达图 + 简表（Funding/OI/DVOL）
- 原因：同时看 BTC/ETH 的多维强度差异。

8. `chart_sentiment_snapshot`
- 图型：F&G 半圆仪表盘 + DVOL 区间定位图
- 原因：情绪与波动需要“状态区间”表达，不适合单纯柱图。

## 简约优先规则

- 优先选“读数快”的图型，少用复杂装饰。
- 若某图新图型可读性下降，回退到简约版本：
- 回退顺序：卡片/100%堆叠/棒棒糖 > 散点 > 雷达。
- 不使用 3D、爆炸饼图、强渐变背景、阴影拟物。

## 缺口数据处理

- 指标缺失时，不强行补图；允许跳过并在正文说明 `data_gaps`。
- 结构图缺一段时，优先降级为文本+单值，而不是伪造占比。
