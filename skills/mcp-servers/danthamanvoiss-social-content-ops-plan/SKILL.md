## Purpose

Plan social content operations rhythm, approvals, repurposing logic, and KPI tracking workflow.

## Use when

- You need the operating system for social production, approvals, and publishing cadence.
- The task is workflow planning, not writing a one-off calendar alone.

## Required inputs

- Channels, cadence targets, and team roles [client-provided].
- Brand voice/offer context from context/BRAND-CONTEXT.template.md and context/CLIENT-CONTEXT.template.md.
- Approval rules, asset constraints, and reporting expectations.

## Safety/authority

- No fabricated channel performance claims or audience metrics.
- No direct publish actions; output process plan and templates only.
- Flag missing governance inputs before recommending cadence.

## Workflow

1. Map end-to-end flow (ideation → production → review → publish → reporting).
2. Define roles, SLAs, and handoff artifacts per stage.
3. Add repurposing and asset-reuse loops across channels.
4. Create risk controls for approval delays and compliance misses.

## Output format
```

- Ops model summary
- Stage-by-stage workflow table
- SLA/ownership matrix
- Risk controls and escalation rules
```

## Quality checks

- Plan includes clear owners and approval gates for each stage.
- Recommendations stay inside supplied capacity and context constraints.
