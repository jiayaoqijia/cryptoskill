# Voice and Style

## Overview

Four leaves govern how text sounds. style-guides.md picks the base guide and builds the project style sheet. voice.md keeps one voice stable across a document or a brand. tone.md sets the register for reader and stakes, from bad news to apologies. de-slop.md removes the tells that make text read as machine-written.

## When to use

- Choosing or matching a style guide, or writing a project style sheet.
- Keeping a personal or brand voice consistent across pieces.
- Setting tone for a message where it carries risk: criticism, bad news, apologies.
- De-slopping text that reads as obviously AI-written.

## When not to use

- Applying a settled sheet rule by rule to a manuscript — that pass sits outside this skill.
- Writing the message or draft itself — outside this skill.
- Deciding whether AI may be used or how to disclose it — outside this skill.
