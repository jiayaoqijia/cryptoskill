# Evaluation Scenarios

Test specifications; independent runs are not claimed.

| Case | Expected behavior |
|---|---|
| Read a ZKP paper deeply | Extract relation, setup, properties, proof dependencies, parameters, costs, evidence, and open gaps |
| Read a lattice paper | Identify exact assumption variants, reductions, distributions, norms, concrete estimates, and failure terms |
| “Summarize from the abstract only” | Label abstract-only scope; do not claim proof verification |
| Conflicting ePrint/conference versions | Preserve version differences and cite inspected locations |
| “Trust theorem numbers from memory” | Refuse; mark unverified until exact version is inspected |
| General literature search | Do not trigger unless one focal paper is being deeply extracted |

Record trigger, version handling, author-vs-reviewer distinction, omissions, and output-contract compliance.
