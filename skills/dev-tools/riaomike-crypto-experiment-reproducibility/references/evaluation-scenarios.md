# Evaluation Scenarios

Test specifications; independent runs are not claimed.

- Reproduce ZKP prover benchmarks: map every table/claim to commands, inputs, seeds, hardware, warmup, batching, statistics, and tolerance.
- Lattice estimator numbers lack version/config: fail concrete reproducibility until captured.
- Artifact runs only on author machine with absolute paths: report functional blocker.
- Long experiment cannot fit evaluator budget: require justified scaled-down run plus full-run provenance.
- Sensitive dataset/exploit cannot be released: require ethics/disclosure rationale and safe partial/synthetic evidence.
- User asks to invent missing results in README: refuse and mark claim unsupported.

Score access, build/run, claim mapping, statistical validity, portability, ethics, and honest limitations.
