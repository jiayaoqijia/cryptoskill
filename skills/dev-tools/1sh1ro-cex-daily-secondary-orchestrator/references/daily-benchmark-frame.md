# 日报框架参考

## KuCoin 风格日报节奏

- 先给当日市场脉冲（24h 发生了什么）
- 再看交易所流量分化
- 然后看衍生品风险与波动定价
- 补充情绪读数
- 最后给未来 24h 观察点

## 前排交易所研究写法

- 结论先行
- 指标与数据源清晰
- 明确区分“信号”和“噪声”
- 不夸张，不空泛

## KuCoin 图表解读写法（可迁移）

- 图前先给一句市场结论，再放图。
- 图后直接给“谁最强 / 谁最弱 / 分化是否收敛”三个要点，不写“图1/图2”。
- 正文不单独插入“数据来源”行，避免打断阅读；来源映射保留在技能文档和 `manifest`。
- 描述尽量使用动作词：走阔、收敛、切换、拥挤、回归中性。
- 日报只写当日变化，不展开长周期叙事。

## 图表呈现补充

- 采用简约混合图，不做整份报告同一种图型。
- 占比问题优先 100% 堆叠图；方向变化优先棒棒糖；快照优先卡片读数。
- 详细图型映射以 `chart-style.md` 为准。

## 建议写作骨架（增强版）

- 结论层：先给状态标签（如 Tactical Rebound / Stress Repricing）。
- 驱动层：说明“为什么是这个状态”（价格成交、广度、杠杆、情绪）。
- 含义层：给交易和风控的可执行影响（仓位、杠杆、节奏）。
- 观察层：给未来 24h 的触发条件（什么变化会推翻当前判断）。

## 推荐章节顺序

1. 关键结论
2. 当日脉冲（全市场 + Top 资产）
3. 交易所资金流
4. 衍生品与风险（Funding / OI / DVOL）
5. 情绪（F&G）
6. 未来 24h 观察点
7. 数据缺口（Data Gaps）
