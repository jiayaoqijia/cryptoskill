# Persuasive Writing

## Overview

Six leaves cover text that must move someone. argument.md fixes the claim-evidence-warrant grammar. persuasion.md arrange it at document scale and handles objections. marketing-copy.md and search-content.md write the page — to convert a visitor, or to be indexed and cited by search and answer engines. bios-pitch.md writes the self-presentation; social-posts.md writes the feed.

## When to use

- Sales pages, ads, hero sections — copy that must persuade, with claims law bound.
- Pages built for search and answer engines: intent matching, citability.
- Structuring an argument or answering objections.
- Bios, pitches and about pages; short-form posts and threads.

## When not to use

- Site engineering: schema markup, robots, crawl configuration — outside this skill.
- Scored bids and proposals — outside this skill.
- Straight news or press statements — outside this skill.
