# Convergence Scoring

## Standard

- **Pugh (1991)**: selection is a criteria matrix — fix the criteria and weights first, then score options against them; the matrix prompts discussion, it does not supply the answer. <https://www.mindtools.com/a2p8vq4/decision-matrix-analysis>
- **Ries, _The Lean Startup_ (2011)**: an idea is a bet on an assumption; the cheapest test that can falsify it beats a confident opinion. <http://theleanstartup.com/>
- ⚠️ House convention: coarse scales beat fine-grained scores, which pretend to a precision the input does not carry.

## Decision rules

1. Criteria are fixed before scoring and before anyone sees which option wins.
2. Use a coarse scale only; if two ideas differ by a fraction of a 1-to-10 score, that gap is noise, not signal.
3. A low-confidence idea can win if its test is cheap and its downside is bounded.
4. An idea that fails a kill criterion leaves the list regardless of its score.
5. Scoring exposes disagreement; it does not manufacture a number.

## Procedure

1. List the criteria: feasibility, cost, reversibility, information value, fit to the brief.
2. Weight or rank them; state which are kill criteria (hard gates) and which are scored.
3. Score each surviving idea on a coarse scale: minus, zero, plus, or 0, 1, 2.
4. Apply the now/later/two-list cut: do now, do later, drop.
5. Check reversibility: reversible options need less scoring; irreversible ones need more.
6. For the top few, name the assumption and the cheapest test; if the test is cheap, prefer the idea that can be tested fastest.
7. Write the shortlist with scores and the reason each item kept its place.

## Anti-patterns

- **Criteria after the fact.** Scoring is reverse-engineered to crown a favorite. Fix: fix criteria first.
- **False precision.** "7.4 versus 7.2" from a gut call. Fix: coarse scale.
- **No kill criteria.** Everything scores, so nothing is ruled out. Fix: hard gates.
- **Reversibility ignored.** An irreversible idea scores like a reversible one. Fix: weight it down.
- **Confidence confused with score.** A confidently-argued idea is treated as a good one. Fix: score the test, not the confidence.

## Done checklist

- [ ] Criteria were fixed before scoring.
- [ ] A coarse scale was used.
- [ ] Kill criteria removed the hard-fail ideas.
- [ ] The now/later/drop cut was applied.
- [ ] The shortlist records scores and the reason each item kept its place.
