## Purpose
Produce a transparent monthly client review based on supplied performance data only.

## Use when
- Preparing monthly/quarterly account review meetings.
- Need a client-safe narrative tied to metrics.

## Required inputs
- Reporting period and supplied metrics.
- Campaign/delivery changes during period.
- Client goals/KPIs and constraints.

## Safety/authority
- No fabricated metrics or attribution claims.
- Interpretation must separate fact from hypothesis.
- No legal/financial advice or guarantees.

## Workflow
1. Summarize provided metrics by objective.
2. Interpret results with confidence levels.
3. List unknowns/data gaps and required follow-up.
4. Propose next-month priorities.

## Output format
```
- Metrics summary
- Interpretation
- Unknowns/data gaps
- Next actions and owners
```

## Quality checks
- Every metric ties to supplied data source.
- Unknowns are explicit before recommendations.
