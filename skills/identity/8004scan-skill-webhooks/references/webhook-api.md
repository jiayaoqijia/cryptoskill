# Webhook API Reference

## Endpoints

### POST /api/v1/webhooks/register — Register Webhook

Create a new webhook subscription.

**Request:**

```json
{
  "webhook_url": "https://yourserver.com/webhook",
  "events": ["feedback.received", "validation.completed"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `webhook_url` | string | Yes | HTTPS endpoint to receive events |
| `events` | string[] | No | Event types to subscribe to |

**Response (200):**

```json
{
  "id": "wh_abc123",
  "webhook_url": "https://yourserver.com/webhook",
  "secret": "generated-secret-store-securely",
  "events": ["feedback.received", "validation.completed"],
  "active": true,
  "created_at": "2026-03-16T00:00:00Z"
}
```

**Validation rules:**
- `webhook_url` must be a URL accepted by the backend
- `secret` is generated by 8004scan and returned once during registration; store it securely

---

### GET /api/v1/webhooks — List Webhooks

List all webhook subscriptions for the authenticated user.

**Response (200):**

```json
[
  {
    "id": "wh_abc123",
    "webhook_url": "https://yourserver.com/webhook",
    "events": ["feedback.received"],
    "active": true,
    "created_at": "2026-03-16T00:00:00Z"
  }
]
```

---

### PATCH /api/v1/webhooks/{webhookId} — Update Webhook

Update webhook URL, events, or active status.

**Request (partial update):**

```json
{
  "events": ["feedback.received", "feedback.revoked", "star.received"],
  "active": true
}
```

| Field | Type | Description |
|-------|------|-------------|
| `webhook_url` | string | New delivery URL |
| `events` | string[] | Replace event subscriptions |
| `active` | boolean | Enable/disable webhook |

---

### DELETE /api/v1/webhooks/{webhookId} — Delete Webhook

Permanently remove a webhook subscription.

**Response (200):**

```json
{}
```

---

### GET /api/v1/webhooks/{webhookId}/deliveries — Delivery History

View delivery attempts for a webhook.

**Parameters:**

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `limit` | int | 20 | Results to return |

**Response (200):**

```json
[
  {
    "id": "del_xyz789",
    "event_type": "feedback.received",
    "status": "success",
    "attempts": 1,
    "last_attempt_at": "2026-03-16T12:00:01Z",
    "response_status": 200,
    "created_at": "2026-03-16T12:00:00Z"
  }
]
```

**Delivery statuses:**
- `success` — 2xx response received
- `failed` — All retry attempts exhausted
- `pending` — Awaiting next retry attempt
