# False Urgency

## Standard

- **Allen, _Getting Things Done_ (2001)**: if a task takes under two minutes, do it now rather than track it. ⚠️ House-applied heuristic: the two-minute rule is for clearing small items, not for yielding to someone else's "now"; it is not a license to skip triage on a loaded queue.
- **Fisher and Ury, _Getting to Yes_ (1981)**: separate the people from the problem; the relationship survives when the negotiation is about the problem, not the person. <https://www.penguinrandomhouse.com/books/324551/getting-to-yes-by-roger-fisher-and-william-ury/>
- **McKeown, _Essentialism_ (2014)**: a clear, unapologetic "no" preserves the relationship better than a resentful "yes" that misses. <https://gregmckeown.com/books/essentialism/>

## Decision rules

1. If a deadline is stated, ask whose it is and what happens if it slips; a consequence-free deadline is a preference.
2. If answering "now" benefits the asker far more than you, it is their urgency, not yours.
3. If the request would survive 24 hours, it was not urgent; apply the test before acting.
4. If the answer is no, say no to the request and yes to the relationship.
5. If the two-minute rule is invoked on a full queue, it loses to triage; small items still take a slot.

## Procedure

1. On any "now", ask the deadline-provenance question: who set it, and what breaks if it slips.
2. Run the 24-hour test: if no one is harmed by a day's delay, treat it as scheduled, not urgent.
3. If a deadline is real, act. If it is soft, renegotiate with a script: restate the goal, name the real constraint, offer a concrete alternative date.
4. When saying no, name what you are protecting, offer what you can do, and do not over-explain.
5. Record the manufactured-urgency pattern so the same asker is not re-scored as urgent next time.

## Anti-patterns

- **Borrowed urgency.** The asker's stress becomes your deadline. Fix: ask the provenance question before acting.
- **Two-minute rule as an override.** Every "quick" item jumps the queue and the deep work never starts. Fix: small items wait for the batch window.
- **Over-explaining a no.** A long justification invites negotiation. Fix: short, kind, final.
- **Urgency by repetition.** The same request is resent until it looks urgent. Fix: one answer, reused, not re-scored.
- **Saying yes to the person, no to the deadline.** Both sides get a fuzzy promise that slips. Fix: name a date you can keep.

## Done checklist

- [ ] Every "now" has a stated source and a consequence if it slips.
- [ ] The 24-hour test ran before any urgent action.
- [ ] Soft deadlines were renegotiated with a concrete alternative.
- [ ] A "no" named what is protected and offered a real alternative.
- [ ] The manufactured-urgency pattern was recorded.
- [ ] The two-minute rule never overrode triage on a full queue.
