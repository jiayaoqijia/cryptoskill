# Templates

| Template | Use | Length | Language |
|---|---|---|---|
| `investment-screen-en.md` | First look, triage, comparison | 1 page | English |
| `investment-memo-en.md` | Standard allocation memo | 3–5 pages | English |
| `investment-report-en.md` | Deep research / PDF | 8–15 pages | English |
| `investment-committee-en.md` | One-page IC summary | 1 page | English |
| `investment-workpaper.md` | Evidence ledger; not a deliverable | As long as needed | English |
| `investment-raporu-tr.md` | Turkish short note | 1–2 pages | Turkish |
| `investment-report-full-tr.md` | Turkish deep report | 8–15 pages | Turkish |

## Rules

- Fill every `{{placeholder}}`; delete internal comments, empty rows and unused sections before delivery.
- A screen is not permission to skip the gate. If a critical control was not checked, say so.
- Deep mode always has a one-page executive summary.
- Keep the report and the workpaper separate: report = argument; workpaper = evidence.
- No composite score, no “safe/guaranteed” language, no position size without constraints.
- Every number needs a source, definition and as-of date.
- The skill is read-only: never sign, approve, bridge, deposit or execute.
