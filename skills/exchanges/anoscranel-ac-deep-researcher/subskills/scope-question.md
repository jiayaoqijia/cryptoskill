# Scope the question

## Standard

- The question exists to serve a decision. The scope contract names the
 decision, the actor, and the cost of a wrong answer before any search
 starts.
- Commit to 2-4 falsifiable hypotheses up front, each with the evidence that
 would refute it. The study then confirms, refutes, or marks each
 under-determined; it never drifts into a topic tour.
- The stake test sets the depth. When a low-quality answer is expensive
 (strategy, money, published artifact), the study runs deep. When a wrong
 answer costs nothing, a shallow run is the correct run, not a failure.
- Question-framing instruments from the review literature transfer when the
 question maps: PICO for intervention questions, SPIDER for qualitative,
 FINER criteria for feasibility.

## Decision rules

- If the ask names no decision, write the most likely decision in one line and
 mark it an assumption. Never invent the requirement silently.
- If one sentence cannot hold the question, the question is not scoped yet.
- Deliverable shapes: verdict memo, landscape map, literature map, evidence
 report. Pick one; the pick drives the report leaf.
- If the scope changes mid-study, that is a new scope: restate hypotheses and
 log the change.

## Procedure

1. Restate the question in one sentence.
2. Name the decision it feeds and who acts on the answer.
3. State the stake: what a wrong answer costs, in one line.
4. Pick the deliverable shape.
5. Write 2-4 falsifiable hypotheses, each with its disconfirming evidence.
6. List what is out of scope, explicitly.
7. Record every assumption as a flagged assumptions line. Flag gaps with ⚠️.
8. Write this into the study plan file on disk before any retrieval.

## Anti-patterns

- Searching before reframing. The decision behind the question usually changes
 the search.
- An unfalsifiable thesis ("AI is changing everything") — no evidence can
 refute it, so no study can test it.
- Scope stated in chat but never written to disk.
- Depth chosen by habit instead of by stake.

## Done checklist

- The decision, actor, and stake are each one line.
- Every hypothesis carries its disconfirmer.
- Out-of-scope list exists.
- Deliverable shape is named.
- Assumptions are flagged, not hidden.

The question worth writing down before any search is what would make the answer wrong, because a question with no possible disconfirming evidence will still produce a report and the report will look like research. Framing the falsifier first is what separates a scope from a topic.
