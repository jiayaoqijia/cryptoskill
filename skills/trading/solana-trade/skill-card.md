## Use Case:

Developers and engineers use this skill to build, test, and review Solana dApps, wallet-signing flows, transaction code, on-chain programs, and generated clients.

## Known Risks and Mitigations:

Risk: The skill can influence high-impact blockchain workflows involving wallet signatures, fees, token programs, and real-value transfers.

Mitigation: Review generated transaction and wallet-signing code before use, with specific attention to cluster selection, fee payer, token program choice, account ownership, signer requirements, and transfer value.

Risk: Solana guidance may become stale as libraries, wallet standards, and testing tools evolve.

Mitigation: Confirm dependency choices and framework recommendations against current project requirements before applying them to production code.
