## Use Case:

Developers and engineers use this skill to draft Hedera SDK setup steps and transaction examples for HBAR transfers, token association, topic messages, account creation, and smart contract calls.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Signing and submitting Hedera mainnet transactions can move real funds or assets if account IDs, token IDs, amounts, fees, memos, or network selection are wrong.

Mitigation: Prefer testnet by default, pin the Hedera SDK version, and require explicit human confirmation of transaction details before signing or submission.
